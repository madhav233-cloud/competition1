# Competition Ladder
This website is primarily used for tracking progress in watching youtube playlist regarding but not limited to DSA courses for placement preparation . 

What makes this site unique is the competitive technical assessment environment it strives to replicate by making bots that also study the same topic and shows their progress . 
This in turn motivates people to study more diligently .
It also displays encouraging quotes to induce the hardworking spirit . 
A dashboard to show the user's weekly progress is available . 
Custom progress bar to account for previous progress is available . 

# Code Detail
HTML File with inline CSS and JS . 

Youtube API used to access playlist data for the given youtube playlist link .
